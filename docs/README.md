## 信息来源优先级

当文档与代码不一致时，按以下顺序核对：

1. `src/data/` 与 `src/systems/` 中的运行时定义。
2. 根目录 `README.md` 和本目录的“当前基线”段落。
3. `迭代记录.md` 中的历史描述。

迭代记录保留提交当时的事实，因此旧记录出现“50 关”“55 类敌人”等数字是正常的，不应批量改写历史。

## 维护检查

发布内容版本时同步检查：

- `package.json` 与 `android/app/build.gradle` 的默认版本是否一致。
- README 的规模表、下载链接和截图是否对应当前代码。
- `generated-art-spec.md` 的运行时资产清单是否与 `BootScene.preload()` 一致。
- 修改 Web 资源后是否执行 `npm run android:sync`，避免 APK 内仍是旧产物。
- 新增存档字段时是否提高数据结构版本并保留旧档迁移。
