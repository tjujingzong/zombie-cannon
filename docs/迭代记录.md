# 迭代记录

> 本文件由 `githooks/post-commit` 钩子自动维护：每次 `git commit` 后，钩子调用 opencode（LLM）读取本次提交并在此**末尾追加**一条记录。
>
> - 钩子激活：`git config core.hooksPath githooks`（仓库已配置）
> - 跳过单次：`OPENCODE_ITERATION_SKIP=1 git commit`
> - 手动补写：直接编辑本文件即可，下次提交不会覆盖
>
> **说明**：钩子在提交*之后*运行，故新生成的记录是工作区改动（未提交）。
> 可把它并入下一次提交；若单独提交本文件，请用 `OPENCODE_ITERATION_SKIP=1 git commit`
> 避免钩子再次为「记录提交」追加一条冗余记录。

## 记录格式

每条记录按如下结构，按时间正序追加（最新在末尾）：

```
## <短hash> <提交标题>

- **时间**：YYYY-MM-DD HH:MM
- **作者**：<作者>
- **变更文件**：<列表，空格分隔>

**变更摘要**
（用 2 至 4 句概括本次改动）

**影响范围**
（受影响模块/系统，顿号分隔）

---
```
